# LMCswap Merchants Directory

Annuaire open-source des commerçants acceptant le token **LMCswap** comme moyen de paiement.

## Format des données

Le fichier `marchands.json` contient la liste complète des marchands.

## Comment ajouter un marchand ?

1. Forkez ce dépôt
2. Ajoutez ou modifiez une entrée dans `marchands.json`
3. Ouvrez une Pull Request
